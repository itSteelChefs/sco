# Exit-path standard

Every `APPROVED_FOR_INTEGRATION` or `INTEGRATED_EVIDENCED` dependency documents: SCO-owned state, tool-owned state, adapter boundary, export format, replacement candidate, removal blast radius, migration strategy, and replacement cost (`LOW`, `MEDIUM`, `HIGH`, `VERY_HIGH`). PostgreSQL/SCO storage remains canonical; derived indexes, embeddings, viewer state, and delivery engines must be replaceable.
